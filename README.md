# @everhoof/everhoof

> Website for internet radio

Requires Node.js 14.18.1 and pnpm 12.6.0. Install pnpm with the [standalone installer](https://pnpm.io/installation/) so it can run alongside this project's Node.js version.

## Build Setup

```bash
# install dependencies
$ pnpm install

# serve with hot reload at localhost:3000
$ pnpm dev

# build for production and launch server
$ pnpm build
$ pnpm start

# generate static project
$ pnpm generate
```

For detailed explanation on how things work, check out [Nuxt.js docs](https://nuxtjs.org).
